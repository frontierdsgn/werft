# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/frontierdsgn/werft/security/advisories/new) (Security
tab → "Report a vulnerability"). Do not open a public issue.

You get an acknowledgement within 7 days. We fix the problem in a private security advisory,
release the fix, publish the advisory and credit you unless you prefer otherwise.

## Supported versions

Only the latest minor release (the newest `v0.y.z` tag) receives security fixes. Sites move to it
with `npm install github:frontierdsgn/werft#vX.Y.Z`.
